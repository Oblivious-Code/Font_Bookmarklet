# Google Font Bookmarklet Maker

A lightweight web tool that turns any Google Font into a custom browser bookmarklet—complete with adjustable font weight and a playful variable-font bounce effect—so you can preview any font on any live website in one click.

🔗 **Live App:** [oblivious-code.github.io/Font_Bookmarklet](https://github.io)

---

## ✨ Features

- **Instant Google Fonts Integration:** Paste any Google Fonts link to generate a ready-to-use JavaScript bookmarklet.
- **Live Interactive Preview:** Test your chosen font directly on the page before installing it.
- **Weight & Bounce Customization:** Adjust font thickness (`100`–`900`) and add a playful wobble animation for variable fonts.
- **Zero Dependencies:** Built with vanilla HTML, CSS, and JavaScript—fast, single-purpose, and lightweight.

---

## 🚀 How to Use

### 1. Generate Your Bookmarklet
1. Open the [Google Font Bookmarklet Maker](https://github.io).
2. Click **Open Google Fonts**, choose a font, and copy its link.
3. Paste the link into the generator and click **Generate Bookmarklet**.
4. Use the sliders to customize the **Weight** and **Bounce**, then click **Copy Bookmarklet Code**.

### 2. Install on Desktop (Chrome, Firefox, Edge, Safari)
1. Show your bookmarks bar (`Ctrl + Shift + B` on Windows/Linux or `Cmd + Shift + B` on Mac).
2. Right-click the bookmarks bar and select **Add Page** (or **Add Bookmark**).
3. Name it after your font (e.g., `Fredoka Font`).
4. Paste the copied `javascript:...` code into the **URL** field and click **Save**.
5. Visit any website and click your new bookmark to apply the font!

### 3. Install on Mobile (Chrome on iOS / Android)
1. Copy your bookmarklet code from the generator.
2. Bookmark any webpage in your mobile browser.
3. Open your **Bookmarks**, edit the bookmark you just saved, give it a short name (e.g., `Font`), and replace the **URL** with your copied `javascript:...` code.
4. Go to the website you want to test, tap the **3 Dots** and press bookmarks, now go to your bookmark you saved.
5. Press your bookmark on your selected website and the font will appear on all of the website page! Unless parts of it are images.
